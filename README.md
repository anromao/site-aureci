# Landing Page - Aureci Sena | Terapeuta Emocional

Landing page profissional, elegante, moderna e 100% responsiva para **Aureci Sena**, Terapeuta Emocional, especializada em **Terapia de Reprocessamento Generativo (TRG)**.

Desenvolvido exclusivamente com **HTML5 e CSS3 puro**, sem nenhuma dependência externa ou biblioteca JavaScript.

---

## 🎨 Identidade Visual

* **Preto Grafite:** `#171717` (fundo principal com iluminação radial suave)
* **Cobre / Marrom:** `#98745F` (títulos, detalhes nobres e botões de destaque)
* **Branco:** `#F5F5F5` (tipografia principal)
* **Cinza:** `#A0A0A0` (textos secundários e legendas)

---

## 🚀 Tecnologias Utilizadas

* **HTML5 Semântico:** Estruturação limpa, acessível e otimizada para SEO.
* **CSS3 Puro:** Flexbox, CSS Grid, variáveis `:root`, efeitos de hover e animações puras via `@keyframes`.
* **Zero JavaScript:** Navegação fluida e menu mobile responsivo via CSS puro (checkbox toggle).
* **Zero Dependências:** Funciona imediatamente com duplo clique no arquivo `index.html`.

## ⚙️ Como Configurar

1. **WhatsApp de Atendimento:**
   * No arquivo `index.html`, procure por `5511989603385` e substitua pelo número real de atendimento com DDD (exemplo: `5511989603385`).
2. **Fotografia:**
   * Substitua `assets/images/aureci-sena.jpg` pela fotografia oficial da profissional.
3. **Qualificações e Redes Sociais:**
   * Localize os comentários `<!-- ESPAÇO RESERVADO PARA QUALIFICAÇÕES -->` e personalize as credenciais e o link do Instagram.
